# Проблемные места текущей архитектуры

## 1. Монолитное хранилище данных (DWH)
- **Описание**: Устаревший Microsoft SQL Server 2008 года не справляется с растущими объемами данных.
- **Влияние на бизнес**: Длительное время ожидания отчетов снижает эффективность работы системы.

## 2. Сложность интеграции новых сервисов
- **Описание**: Необходимость дописывать большое количество бизнес-логики в DWH при интеграции новых направлений.
- **Влияние на бизнес**: Увеличение time-to-market для новых продуктов и сервисов, сложность масштабирования бизнеса.

## 3. Отсутствие единого подхода к данным
- **Описание**: Нет централизованного управления данными и их качеством, отсутствует каталог данных.
- **Влияние на бизнес**: Неточные данных, неточная аналитики, сложность поиска нужной информации.

## 4. Ограниченные возможности для пользователей
- **Описание**: Отсутствие удобного инструмента для самостоятельного создания отчетов бизнес-пользователями.
- **Влияние на бизнес**: Зависимость от ИТ-специалистов для создания отчетов, увеличение времени получения аналитики.

## 5. Неэффективная обработка больших объемов данных
- **Описание**: Текущая архитектура не оптимизирована для работы с большими данными.
- **Влияние на бизнес**: Низкая производительность, высокие затраты на инфраструктуру, ограниченные возможности аналитики.

## 6. Сложность управления доступом к данным
- **Описание**: Отсутствие системы управления доступом с учетом различных ролей и уровней.
- **Влияние на бизнес**: Риски нарушения конфиденциальности данных, сложность соблюдения требований законодательства.

## 7. Отсутствие единой стратегии работы с данными
- **Описание**: Нет разделения на домены и определения владельцев данных.
- **Влияние на бизнес**: Размытая ответственность, сложность координации изменений, неэффективное использование данных, которые есть в компании.
